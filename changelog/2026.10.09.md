# 2026.10.09 (2026-10-09)

## Changes

- Publish every document reachable through the Sphinx toctree as a matching Notion page hierarchy when automatic publishing is enabled.
  ([#634](https://github.com/adamtheturtle/sphinx-notionbuilder/issues/634))
- Validate decoded Notion upload payloads without type-checker suppressions.
  ([#1025](https://github.com/adamtheturtle/sphinx-notionbuilder/issues/1025))
- Type Sphinx document metadata using its actual scalar and author-list values.
  ([#1031](https://github.com/adamtheturtle/sphinx-notionbuilder/issues/1031))
- Type Notion mention role callbacks using the Docutils role argument domain.
  ([#1032](https://github.com/adamtheturtle/sphinx-notionbuilder/issues/1032))
- Require `sphinx-iframes` 1.2.0 for its dedicated node type while retaining support for the full set of `sphinxcontrib-video` options.
  ([#1060](https://github.com/adamtheturtle/sphinx-notionbuilder/issues/1060))
- Require `sphinx-iframes` 1.2.1 and use its upstream video directive with caption support.
  ([#1085](https://github.com/adamtheturtle/sphinx-notionbuilder/issues/1085))
- Publish native Markdown release notes and use the same notes in documentation where available.
